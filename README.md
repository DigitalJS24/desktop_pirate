# 🏴‍☠️ Десктопні Корсари та Міньйони (Desktop Pirates & Minions)

Інтерактивний десктопний улюбленець (Desktop Mascot) для Windows з романтичною парою піратів, папугою та кумедними **Міньйонами (Minions)**!

---

## ⚡ Швидкий запуск без Python (EXE файл для Windows):

У корені проекту створено повністю автономний файл:
👉 **[`DesktopPirate.exe`](file:///e:/Projects/desktop_pirate/DesktopPirate.exe)**

- Не потребує встановленого Python або будь-яких бібліотек.
- Містить у собі всі звуки, анімації, спрайти піратів, піратки, папуги та міньйонів.
- Запускається без консолі у фоновому режимі одним подвійним кліком!
- Можна перенести на будь-який інший комп'ютер з Windows 10/11 і він одразу працюватиме!

---

## 🍏 Як запустити та зібрати для macOS (Apple Silicon M1/M2/M3 та Intel):

Код повністю адаптовано для macOS (рідне аудіо `afplay`, розташування ярликів робочого столу Finder у правому кутку, підтримка прозорих вікон):

### 1. Швидкий запуск на Mac:
У терміналі Mac просто виконайте:
```bash
chmod +x run_pirate.sh
./run_pirate.sh
```
Він автоматично створить оточення, встановить залежності та запустить піратів у фоні!

### 2. Створення автономного `.app` пакета для Mac:
Запустіть скрипт збірки:
```bash
chmod +x build_mac.sh
./build_mac.sh
```
У результаті в папці `dist/` створиться готовий застосунок:
- **`dist/DesktopPirate.app`**
- **`dist/DesktopPirate-macOS.zip`**

### 3. Автоматична збірка через GitHub Actions:
У проект додано готовий workflow [`.github/workflows/build_mac.yml`](file:///e:/Projects/desktop_pirate/.github/workflows/build_mac.yml). Якщо завантажити проект на GitHub — безкоштовні сервери GitHub (на базі macOS) автоматично скомпілюють для вас готовий `.app` архів, доступний для завантаження у вкладці **Actions**!

## 👥 Персонажі:

### 1. Капітан Пірат
- Ходить, бігає, стрибає по робочому столу та панелі завдань.
- Дереться вгору по краях екрана (Rigging climb) та повзає по стелі.
- Стрибає, ходить і ціпляється руками за **ярлики на робочому столі**.
- Закоханий у піратку: бігає за нею, ловить і палко цілує!

### 2. Дівчина-Піратка (Piratess)
- Витончена піратка з довгим каштановим волоссям, у рубіновому корсеті та з білим пером на капелюсі.
- Грає з капітаном у погоню: дражнить його і тікає через увесь екран!
- Коли капітан її наздоганяє — дарує солодкий поцілунок 💕.

### 3. 🍌 Міньйони (Minions)
- **З'являються після поцілунку**: щоразу, коли Капітан та Піратка цілуються (або через меню), лунає кумедний голос міньйона (**`minion.wav`**), і між піратами **вистрибує яскравий жовтий Міньйон з бананом у руці**!
- **Образ**: кругла капсульна форма, сріблясті окуляри, джинсовий комбінезон і банан 🍌!
- **Поведінка**:
  - Бігають за піратами перевальцем, стрибають по ярликах та вигукують:
    - *«Bello! 🍌»*
    - *«BANANA!! 🍌🍌»*
    - *«Papoi! 🍌»*
    - *«Poopaye! 👋»*
    - *«Tulaliloo ti amo! 💕»*
    - *«Bi-do bi-do bi-do! 🚨»*
    - *«Капітан! Банана!»*
  - Клік по міньйону змушує його щасливо підстрибнути та закричати *«BANANA!!»*.
  - Міньйона можна переносити мишкою — він кумедно дриґатиме ніжками.

### 4. Автономний Папуга
- Сидить на плечі капітана або вилітає на розвідку на ярлики.
- Повертається назад на плече на свист капітана.
- Після поцілунку батьків радісно кричить: *«Гірко! Кра-а! Банана!»*.

## 🎮 Керування:

- **Лівий клік по персонажу**: реакція (удар шаблею, повітряний поцілунок, крик міньйона «BANANA!»).
- **Перетягування (Drag & Drop)**:
  - Будь-кого можна підняти і переносити мишкою.
  - Якщо перетягнути пірата і піратку впритул одне до одного — вони **поцілуються, і між ними з'явиться міньйон**!
- **Правий клік (меню)**:
  - 💖 **«Почати романтичну погоню»** — піратка починає втікати, а пірат кидається навздогін!
  - 💋 **«Поцілуватися зараз»** — поцілунок із серденьками та появою міньйона.
  - 🍌 **«Покликати міньйона (BANANA!)»** — викликати ще одного міньйона.
  - 🧹 **«Прибрати міньйонів»** — відправити міньйонів за бананами, якщо їх стало забагато.
  - 🎯 **«Стрибнути на ярлик»** — стрибок на найближчу іконку на робочому столі.
  - 🦜 **«Покликати папугу назад»** / **«Відпустити папугу»**.
  - 📏 **«Розмір»** — зміна масштабу.
  - 🔊 **«Звук»** — увімкнення/вимкнення звуків.
  - ⚓ **«Повернути всіх на робочий стіл»**.
  - 🚪 **«Відплисти (Вийти)»** — закриття програми.
